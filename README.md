**Policy Tracking** is an enterprise-level web application developed using .NET Core 8 MVC to manage and track policy-related processes. The project is designed with a focus on sustainability, scalability, and clean code principles, structured based on the **N-Layer Architecture** pattern.

---

## 🚀 Technologies & Architectures

- ✅ **.NET Core 8 MVC**
- ✅ **N-Layer Architecture** — Modular and loosely-coupled layered structure  
- ✅ **Interceptor Logging** — Application-wide logging through interception points  
- ✅ **SignalR** — Real-time tracking of online users  
- ✅ **FluentValidation** — Validation of incoming requests and user inputs  
- ✅ **ASP.NET Core Identity** — Authentication and role-based authorization
